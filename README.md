# Wenyuan Xu Homepage

This repository is a Digital Garden static site for Wenyuan Xu's personal homepage.

The editable source note lives in the Obsidian vault:

```text
/Users/wenyuan/Documents/Obsidian Vault/Wenyuan Xu/index.md
```

The avatar used by the note lives next to it:

```text
/Users/wenyuan/Documents/Obsidian Vault/Wenyuan Xu/_assets_index/IMG-20260515100457094.jpg
```

Publish from Obsidian with:

```text
Digital Garden: Publish Single Note
```

Cloudflare Pages should be configured with:

```text
Framework preset: None or Eleventy
Build command: npm run build
Build output directory: dist
Root directory: empty
Environment variable: NODE_VERSION=22
```

The repo uses Digital Garden's Eleventy template. In normal use, edit only the
Obsidian Markdown file and publish from Obsidian.
